## What the automated tests cover
- **Rules/hosts** (`packages/shared/test`): damage formula, hidden answer keys in `ROUND_START`, duplicate/stale/unauthorised answers, ability charge after 3 correct, shield blocking, KO, timeout draw, disconnect forfeit, reconnect within grace, full bot match; race physics (careful player beats fast guesser), race positions, duplicate race answers; sentence grading with multiple valid orders and diagnostics; sentence duel scoring with second attempts; ranking tiers/Elo/placement; protocol validation strips client-sent `damage`.
- **English Conquest rules**: setup (capitals, income, question phase), gold + focus from correct answers, invalid actions rejected, deterministic attacks whose preview matches the result, full bot-vs-bot games always terminate with a consistent state. (Victory conditions are exercised by those full games but not asserted individually.)
- **Cosmetics shown online**: every catalog hero/vehicle (incl. new ones) is accepted, unknown ids fall back; titles/frames pass only when default or backed by a server-recorded achievement; made-up ids never pass.
- **Word Battle tactics**: each tactic applied server-side and visible to both players; Striker's self-damage only on wrong answers (not timeouts); a bot-vs-bot simulation keeps every tactic within a fair win-rate band vs Balanced for rookie, adept and champion bots. Online: tactics chosen in READY reach the host, invalid tactics are rejected.
- **Tournament brackets**: 3 players → 4-bracket with a bye for seed 1; 6 players → 8-bracket with byes for seeds 1–2; winners advance to a champion with correct placements; impossible results rejected; draws decided by correct answers, then speed, then seed; 3–8 players enforced.
- **EscapeCoopHost** (FakeClock): answers checked server-side and shared (last attempt, who opened a lock); opened locks cannot be re-solved; outsiders, unknown locks and early answers rejected; shared hints; brute-force limit; text answers normalised; the team wins together; timeout is a shared draw and leavers do not stop the team; protocol limits.
- **ConquestHost** (FakeClock): question sent only to the active player without the key; answers/actions from other players rejected; correct answer → gold + focus; illegal actions rejected by the rules; question and action-phase timeouts; disconnected player skipped; leaver's islands turn neutral while the game continues; last player standing wins by forfeit; a full 2-player game with real attacks reaches a decision; protocol rejects malformed conquest intents and conquest in matchmaking queues.
- **Learning engine**: scheduler interval growth/shrink, a missed word returns in a *different* item, mastery and weak topics, no proficiency without evidence, recency avoidance, placement moves up/down; rule-based writing check (stance, reasons, concession, common errors) and the 8-point debate checklist (each habit detected independently; weak texts meet none); **mistake review** replays public items first, replaces server-only ranked items with public items sharing knowledge components, and never picks items more than one level away.
- **Private ranked pool loading**: items overlapping the public bank or the public sample are rejected; production never falls back to the public sample unless explicitly allowed; a valid private file loads, an invalid one disables ranked; a production server without a private pool answers `RANKED_UNAVAILABLE` for ranked queues while casual queues work; `/health` reports the source without content. `RANKED_SQL=… pnpm db:test` verified that the 99-item private pool loads into PostgreSQL and is hidden from `anon`/`authenticated` by RLS.
- **Ranked development sample (public)**: every option item grades its key as correct and every distractor as wrong; every sentence puzzle accepts each listed answer; no ranked prompt repeats a public prompt (so keys cannot be looked up offline — this test found and replaced 5 overlaps); ≥ 30 option items per bracket.
- **Content**: schema/references/duplicates/Hebrew presence/tile consistency; listening scripts; escape-room puzzles; Real Life dialogue graphs (unique ids, Hebrew feedback on every choice, a best reply on every node, every path reaches an end); every option item grades itself correctly; every sentence accepts all listed answers; enough items per bracket for each game.
- **i18n**: Hebrew has every English key with matching placeholders; numeric ranges in Hebrew are wrapped in directional isolates so they are not displayed reversed.
- **Server integration (real WebSocket clients)**: guest tokens, invalid tokens, origin allow-list, HELLO required; private room → ready → round; answer keys hidden; intruder rejected (`NOT_IN_MATCH`); replayed `msgId` and second answer rejected (`DUPLICATE`); server-computed damage; opponent's answer text not leaked; forfeit; **server-computed XP/shards/achievements stored and returned by `/api/me/wallet`, no shards for the forfeiting player**; disconnect + reconnect with snapshot; room closed when full; 3-racer Grammar Race room started by the host (`ROOM_START`); **friends' tournament** (3 players: start refused with 2 and for non-hosts, queues blocked for members, a bye, a forfeited semi-final advances the winner, the final starts automatically, a leaver gives a walkover, the champion's wallet gets the achievement and shards); **co-op Escape Room** (2 players: a wrong answer is shared, unknown locks rejected, the team escapes together, unranked, shards earned); **3-player English Conquest room**: queue rejects conquest, only the active player gets the question, forged answers/illegal actions rejected, turn passes, leavers eliminated, last player wins, unranked; rematch → new private match; ranked queue → server-only ranked items, ±32 MMR, placement 1/5, leaderboard + `/api/me/ratings`; ready-check timeout cancels; friend request/accept/challenge/invite → match; block removes friendship and blocks room join; report; malformed message; rate limiting.
- **RLS (PostgreSQL)**: users cannot write ratings, wallets, achievements, match results, cosmetics or friendships; cannot forge learning events for others or as `server`; cannot read ranked items/answer keys or others' matches/events; cannot equip unowned cosmetics; anon read limits; service role can write; account deletion cascades.
